# 🇬🇧 English

## 🎯 About The Game

**Dice Duel** is an online multiplayer game where luck meets strategy.

Players challenge each other in real-time dice battles, aiming to roll the highest score and defeat their opponents. Powered by WebSockets and Socket.IO, the game delivers a fast, seamless and engaging multiplayer experience.
